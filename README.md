## 📥 Instalação

### Pré-requisitos

Antes de executar o projeto, certifique-se de possuir:

- GCC instalado e configurado.
- Biblioteca Raylib instalada.
- Git instalado (opcional, para clonar o repositório).

### Clonando o repositório

```bash
git clone URL_DO_REPOSITORIO
```

### Compilação

Execute o comando abaixo para compilar o projeto:

```bash
gcc -Wall -Wextra main.c -o main.exe -lraylib -lopengl32 -lgdi32 -lwinmm
```

### Execução

Após a compilação, execute:

```bash
./main.exe
```

## 🕹️ Como Jogar

### Objetivo

O jogo deve ser jogado com 2 jogadores na mesma máquina, compartilhando o mouse, sendo um turno de cada jogador. Antes de começar deve-se decidir quem começara a partida com a brancas. É importante avisar que quando uma peça chegar no final do tabuleiro, nessa damas a peça não vira Dama!
